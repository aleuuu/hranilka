# Хранилка

Приложение для Windows, которое наводит порядок в фото и документах по вашим словам.
Напишите, как хотите разложить файлы, — Хранилка предложит папки и понятные имена, а вы решите, применять ли.

- **Работает на вашем компьютере.** Файлы смотрит локальная модель через [Ollama]; ничего не уходит в интернет.
- **Ничего не удаляет.** Только переносит и переименовывает, всё можно вернуть одной кнопкой в течение 30 дней.
- **Сначала показывает план.** Каждое решение можно отклонить, переименовать или перетащить в другую папку.
- **Учится на ваших правках.** Перетащили файл и нажали «Запомнить» — похожие файлы лягут туда же.

## Своя структура папок

На экране «Разобрать» можно выбрать «По моей структуре» и задать папки самому — кнопками, списком
(«Видео — по годам и месяцам», «Мемы: смешные картинки с подписями») или взять уже существующие подпапки.
Модель тогда только выбирает папку из вашего списка, а что не подошло — кладёт в «Разобрать вручную».
У каждой папки: что класть (тип, пояснение, примеры), имена (как есть или понятные) и подпапки сами
(по годам, по месяцам, по проектам). В разбор идут и установщики с архивами; недокачанные файлы не трогаются,
вложенные папки переезжают в «Разобрать вручную» целиком. Структура запоминается для каждой папки.

## Чтобы файлы одного проекта не разъезжались

На странице «Правила» три простые вещи, и все они срабатывают раньше модели:

1. **Мои проекты** — название и ключевые слова. Если они есть в имени файла, на скриншоте или в описании,
   файл ляжет в «Проекты/<название>». Проекты из плана можно запомнить одной кнопкой.
2. **Правила** — «если имя / текст / папка / тип → в такую-то папку», по желанию без переименования
   или с датой в начале имени. `{год}` в пути подставит год файла.
3. **Выученные примеры** — кнопка «Запомнить» после перетаскивания в плане. Похожие файлы
   (по смыслу, через `bge-m3`) сразу переезжают туда же, и в следующих сортировках тоже.

## Установка

Скачайте `Хранилка_x.y.z_x64-setup.exe` со страницы релизов и запустите. Права администратора не нужны.

При первом запуске Хранилка проверит компьютер и скачает модель (4.5–9.5 ГБ) — если Ollama не установлена,
поставит и её. Нужна Windows 10/11; видеокарта желательна, но не обязательна.

Если загрузка модели стоит на месте — отключите VPN на время загрузки или добавьте `registry.ollama.ai`
и `*.r2.cloudflarestorage.com` в исключения.

## Как устроено

| Часть | Где | Что делает |
| --- | --- | --- |
| Интерфейс | `src/` — React + TypeScript | Онбординг, выбор папки, анализ, план «было/станет», дотюнивание, результат, история, правила, модели, настройки и темы, слежение за папками |
| Приложение | `src-tauri/` — Rust, Tauri 2 | Окно, трей, проверка ПК, Ollama и загрузка моделей, перенос файлов с журналом и откат |
| Движок | `engine/engine.py` — Python | Сканирование, описание файлов моделью, группировка, правила и выученные примеры, план, дотюнивание |

Модели: `gemma3:12b` («Точная») или `gemma3:4b` («Быстрая») смотрят на картинки и читают документы,
`bge-m3` группирует похожее. Проекты с кодом, программы и ваши собственные папки переносятся целиком.

Журналы отмены, кэш описаний, превью, настройки и выученные примеры лежат в `%APPDATA%\ru.hranilka.app`.

## Сборка

Нужны Node.js, Rust и [uv](https://docs.astral.sh/uv/).

```bash
npm install
npm run tauri dev      # разработка: движок запускается из engine/engine.py
npm run tauri build    # установщик: движок собирается в engine/dist через PyInstaller и кладётся внутрь
```

Установщик появится в `src-tauri/target/release/bundle/nsis/`.

## Что пока не сделано

- Видео и музыка разбираются по имени и дате, без анализа содержимого.
- Антивирусы иногда настороженно относятся к упакованному Python-движку — это ложная тревога.
